# BuildWise AI

## Start here
1. `.agent-control/SUMMARY.md` — short project map and change ledger.
2. `.agent-control/MASTER-ARCHITECTURE.md` — mother architecture and decisions.
3. `docs/PHASES/` — phase-by-phase scope.
4. `.agent-control/STATE.md` — current execution/runtime state.
5. `tests/` — verification.

BuildWise AI is a Real Estate Operating System (REOS), not a simple CRM.

### Canonical implementation areas
- UI entry: `index.html`
- Current app: `buildwise-app.js`
- Shared/core: `src/core/`
- Domains: `src/domains/`
- AI: `src/ai/`
- Agent runtime: `src/agent-control/`
- Backend: `supabase/`
- Tests: `tests/`
- Coordination: `.agent-control/`

Do not develop new features in legacy/duplicate files.
