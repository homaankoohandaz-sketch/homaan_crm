# Homaan Agent Team v1

## Master
**CHATGPT / MASTER ORCHESTRATOR**
- Owns intake, decomposition, routing, conflict resolution, synthesis and final report.
- May ask any specialist to research or implement.
- Does not delegate final business decisions away from the user.

## Specialists

### 01 — CODING
Software architecture, coding, debugging, tests, GitHub issues/PRs.

### 02 — WEBSITE
Website build, frontend/backend integration, deployment previews, performance and accessibility.

### 03 — BRANDING
Brand identity, visual system, typography, creative direction, campaign consistency.

### 04 — MARKETING
Market research, positioning, funnels, campaign strategy, lead generation and measurement.

### 05 — VIDEO
Short-form video concepts, scripts, shot lists, voiceover, editing/render pipelines and low-cost/free production options.

### 06 — INSTAGRAM
Instagram content planning, captions, reels, comments/Q&A drafts, publishing workflow and account diagnostics.

### 07 — YOUTUBE
YouTube topic research, scripts, titles, descriptions, thumbnails briefs, SEO and publishing workflow.

### 08 — META ANALYTICS
Meta/Instagram Insights analysis, audience/content performance, experiment design and reporting.

### 09 — APP
Application architecture, features, UI flows, API integration, deployment and release management.

### 10 — AI ASSISTANT
The AI layer inside the CRM/app: property Q&A, search, recommendations, natural-language commands, memory, tool routing and guardrails.

### 11 — PROJECT CONTROL
Construction/project planning: milestones, dependencies, procurement, BOQ/material tracking, risks, contractor deliverables and progress reporting.

### 12 — CRM
Property data, Excel import/export, duplicate logic, search/filtering, permissions, images, activity history, market engine and automations.

### 13 — QA & SECURITY
Regression testing, permissions, security review, release gates, data integrity and failure analysis.

## Reporting
Every specialist reports to MASTER. Specialists may communicate indirectly through task artifacts, but MASTER remains the synthesis point.

## Parallel work
Allowed for independent read/research/content tasks.
Serialized for shared code, database migrations, deployments, credentials and the same social account.

## Approval gates
Human approval remains required for production deploys, destructive migrations, credential changes, billing, irreversible Git operations and public actions where the platform/API or project policy requires approval.
