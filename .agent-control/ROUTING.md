# Master Routing Rules

User request → classify → create task contract → assign the smallest useful specialist set → parallelize safe work → collect evidence → QA → reconcile → final synthesis.

## Core routes
- Fix CRM import → CRM + Coding + QA
- Build feature → App + Coding + QA
- Land/owner analysis → Land + Market + Deal
- Builder sales system → Sales Engineering + CRM + Marketing
- Deal matching → Deal + CRM + Market
- Construction issue → Project Control + CRM + AI Assistant
- Contract/document → Document + relevant domain specialist + QA
- AI feature → AI Assistant + CRM + App + QA
- Deployment → DevOps + Coding + QA

## Conflict rule
Preserve competing findings, verify evidence with the relevant reviewer, then Master synthesizes. Do not hide uncertainty.

## Human gates
Production deployment, destructive schema changes, secrets/authentication changes, irreversible Git operations, billing/cost commitments and sensitive public social actions require explicit human approval.
