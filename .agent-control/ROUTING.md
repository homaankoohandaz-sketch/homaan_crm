# Master Routing Rules

User request -> classify -> create task contract -> assign specialist(s) -> parallelize where safe -> collect reports -> QA -> reconcile -> final answer.

## Examples
- "Fix CRM import" -> CRM + Coding + QA
- "Build landing page" -> Website + Branding + QA
- "Make 10 reels" -> Marketing + Video + Instagram
- "Why did Instagram growth fall?" -> Meta Analytics + Instagram + Marketing
- "Add AI property assistant" -> AI Assistant + CRM + App + QA
- "Construction project is delayed" -> Project Control + CRM
- "Build a new feature" -> App + Coding + QA

## Conflict rule
When specialists disagree:
1. Preserve both findings.
2. Ask the relevant reviewer to verify evidence.
3. Master decides the task routing/technical synthesis.
4. User retains final authority for business, financial and irreversible decisions.

## Social rule
Analytics/read operations can be autonomous when authorized. Public posting, sensitive replies, account changes and actions that may violate platform rules require the configured approval gate.
