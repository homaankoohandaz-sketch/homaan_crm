# External Agent Sources / Building Blocks

This is a curated reference list. We should reuse architecture, patterns and compatible code where licensing permits, rather than blindly copying entire repositories.

## Orchestration / coding
1. Untrivial-ai/agent-orchestrator — coding-agent supervision, isolated workspaces, Kanban/PR/CI feedback loops. Apache-2.0.
2. c9r-io/orchestrator — declarative control plane for Codex/Claude/OpenCode/Gemini CLI with workflows, secrets, observability and recovery. License must be checked before code reuse.
3. hyw007726/multi-agent-orchestrator-skill — parallel coding agents with worktree isolation, task contracts, validation and handoffs. License must be checked before code reuse.
4. Open-Makers/ai-coding-agents-orchestrator — specialist software team pipeline with PM/Coder/QA/UX/Security roles. Open source; verify current license before copying code.

## Marketing / social
5. Meshpilot-AGI/ai-social-agent — multi-brand social pipeline for Instagram Reels, YouTube Shorts, X and LinkedIn, with approval gates.
6. YusufSizmaz/social-agent-ai — self-hosted social automation with content generation, publishing, analytics and strategy optimization.
7. Shivay00001/digital-marketing-agents — multi-agent SEO/blog/social marketing with reviewer loops.
8. kushalsamani/social-media-ai-agent — CrewAI workflow for market research, strategy, content calendar, social posts, reels, blogs and SEO.
9. SamurAIGPT/open-ai-social-agent — social listening, creator discovery, publishing and trend research across major platforms.
10. unifapi-agent/agents — public-data research agents for Instagram, YouTube, TikTok, X, LinkedIn, Reddit and SEO.

## Instagram
11. alsk1992/instagram-ai-agent — Instagram content generation, scheduling, comments and analytics-oriented workflow. Automation must respect Meta/platform rules and account safety.

## App AI
12. Corza-AI/corza-agent-framework — web-app-first agent framework with persistence, streaming, multi-user isolation and team-of-agents orchestration. MIT.

## Microsoft reference
13. microsoft/Agent-Framework-Samples — multi-agent marketing example with research, strategy, copy, social and visual production.

### Rule
External repositories are references. Before importing code, verify the repository's current license and preserve required attribution/notices. Do not commit secrets or copied credentials.
